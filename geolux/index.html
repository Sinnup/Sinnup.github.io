Geolux.

Geolux is a sketch solution: a CRUD for locations using Google Maps and Firebase for storing data and files related to the locations. Its main functionality is that it extracts the coordinates information from an image in order to relate the information of a specific location and its photo.

How it works

From photo to place

  • 📷
    Photo in, coordinates out
    Photos carry GPS metadata in their EXIF tags. Geolux reads it from the image to get the exact latitude and longitude, so there is no need to type or pick the position by hand.
  • 🗺️
    Locations on Google Maps
    Each location is drawn on a Google Map, tying the stored information to a real place and its photo.
  • 🔥
    Firebase for data and files
    Location records and their related files are stored in Firebase, giving the CRUD (create, read, update, delete) a persistent cloud backend.
