Faci.

Faci sells practical gadgets sourced from AliExpress and delivered around Mexico City's metro. It is a one-person business, so I run it like a software pipeline: a Google Sheet is the database, AppSheet is the point of sale, a PWA catalog redeploys on every git push, and one Claude Code command takes a new product from a supplier link to a live Facebook Marketplace listing. Neither AliExpress nor Marketplace gave me an API for this, so the agent uses the browser.

The pipeline

One command, from supplier link to live listing

/ofrecer-nuevos-productos is a Claude Code slash command that chains five smaller commands. They run in order, stop at the first failure and print a one-line status between steps. Each step reads and writes a status column in the Sheet ("Imagenes descargadas", "Publicado"), so a batch can be re-run at any time and only picks up the rows that are still pending. Mechanical steps run on Haiku; the ones that need vision, copywriting or driving a browser run on Sonnet.

  1. Download the supplier photos
    Haiku
    For every row with a product link and no images yet, Claude in Chrome opens the AliExpress page (rendered by JavaScript, no API) and a custom skill extracts the full gallery into a folder named after the product. Then the row is flipped to "Si" through the Sheets API.
  2. Convert formats
    Haiku
    A shell script turns AVIF and WebP into JPG, which is what Marketplace accepts reliably.
  3. Translate the photos
    Sonnet
    Supplier images have English marketing text printed on them. A skill rewrites that text in Spanish and removes the supplier's brand marks.
  4. Write the listing
    Haiku
    A copywriting skill writes title, description and five tags, applies my delivery rules (price bands mapped to metro zones, fixed schedule block) and writes everything back to the Sheet.
  5. Publish to Facebook Marketplace
    Sonnet
    For each row in stock and not yet published, the agent fills the Marketplace form in Chrome: title, price, category, condition, description, up to 20 tags, location and meetup delivery. It uploads the whole gallery through the hidden file input, confirms success by the redirect to the selling page, and only then marks the row "Publicado".

How it's built

A Sheet as the source of truth

  • Google Sheets as the database, AppSheet as the POS
    Inventory, sales and line items live in one Sheet that AppSheet turns into a point-of-sale and stock app. An Apps Script onChange trigger rebuilds the monthly summary so AppSheet can show revenue and profit per month. "In stock" is a formula on the inventory tab, so the catalog and the publisher never offer what I don't have.
  • A catalog that deploys itself
    A Python generator reads the Sheet and builds a single-file PWA with categories, search, a cart and checkout by WhatsApp with an itemized message. Only products with stock and photos are included. Deploy is a git push: Fluent Ops picks it up, no CLI. In CLAUDE.md, "feature complete" means regenerate, commit and push, so one phrase ships a catalog update.
  • Clear tool boundaries for the agent
    CLAUDE.md maps every tab and column and sets one hard rule: Sheets go through the API, Chrome is only for AliExpress and Marketplace. It also sets the working mode (process the whole batch, stop only on a real blocker) and a token policy: creative writing only for marketing copy, terse everywhere else.
  • Skills that remember what broke
    The Marketplace publishing skill keeps a technical-notes block with the selectors and pitfalls found in real runs: how to pick a category with find, why WebP must become JPG first, which column must never be overwritten. Every failure makes the next run cheaper.
  • Pricing with formulas, not guesses
    Price tabs compute cost, real profit and markup per product for Marketplace, plus separate price and cost calculators for Mercado Libre fees.
